# BCSR 设计复审：从边界注意力到几何观测

日期：2026-09-12。范围：当前 v1 代码、用户提供的 FressDet v2、相关原始论文与可执行
局部模型检查。下文 v2 尚未接入 detector，数学 probe 不是完整 MODA 的实验结果。

## 结论与主张调整

**O² 仍适合做基线，但当前 BCSR v1 的理论和新颖性不足以直接作为强论文定稿。**
问题不在于缺少公式：学习权重没有明确统计含义，沿边过早池化会丢掉部分角度信息，
隐藏特征残差与框误差减少之间也没有确定联系。继续堆叠 gate 或 attention 无法补齐。

推荐主线收紧为：**多光谱边界观测对旋转框各自由度的约束不同，应保留这种差别，
根据经过校准的观测可靠性，显式求解一次受约束的几何修正。** 先证明该机制在真实
MODA 的预测框附近成立，再谈论文贡献。暂不新增缩写或声称物理波长建模。

## FressDet 的理论为什么更完整

本地来源为 research/references/FressDet/paper/arXiv-2607.05148v2/main.tex，
重点是 Spectral Implicit Warp、Implementation-Aligned Equivariance Analysis、
Oriented-Aware Head。它将问题、结构和可验证性质连在一起：

| 问题 | 实际结构 | 可推导性质 |
|---|---|---|
| 旋转后特征组织改变 | 保留群方向维，卷积权重按群作用绑定 | 适配离散格点条件下的 C4 等变关系 |
| 自由光谱偏移会跨越通道次序 | 正增量累加并归一化生成采样位置 | 有限实数模型下顺序保持；浮点下需检查数值退化 |
| 分类和几何需要不同读出 | 分类沿群维平均，边分布循环绑定，角度圆周读出 | 各输出与其对应变换律相容 |

这些是结构性质，不是精度必然更高的证明。附录也给出格点、hard routing 唯一赢家、
非零角度合成向量等条件。值得学习的是**约束被写进算子、命题能被测试**。
当前 BCSR 仅有同一矩形等价参数化给相同结果的性质，层次弱于整条网络的旋转等变。
不能把集合平均的置换不变性包装成新的旋转等变理论。

## v1 具体问题

| 当前设计 | 审查判断 | 应如何验证或修正 |
|---|---|---|
| 按预测框读取四边 | 合理，但框驱动特征对齐已有先例 | 贡献限定在光谱观测如何约束几何 |
| 每边 4 点先平均 | 存在局部角度信号抵消反例 | 保留点位及其带符号切向坐标 |
| query/key softmax 波段权重 | 不是误差方差、置信概率或 Fisher 信息 | 估计位移观测误差，并检查校准 |
| inside、outside 及其差值 | 第三项是前两项线性组合；随后接线性 key/value，未增加表示能力 | 只是参数化选择；改为法线方向多点剖面 |
| 四边汇成 256 维残差 | 网络可能学会映射，但无法保证是下降方向 | 经过明确几何 Jacobian 变成框修正 |
| 一处内外采样距离 | 框偏离时可能两侧同属背景；强对比可能来自邻车 | 有限搜索剖面、query 条件选择、有效性与偏移范围限制 |
| stride4 浅层分支 | 1–2 像素内外差可能低于其分辨能力；参数少不等于激活占用小 | 按目标短边分组，比较 stride2/4 或原分辨率轻量读出 |
| 无增强且从头训练 | 与主配方一致，但 O² 没有继承 FressDet 的结构等变约束 | 先确认 O² 基线收敛 |
| 不同边权重看起来不同 | 注意力图变化不等于有用的定位信息 | 用干预和预测误差验证 |

OBB 边是标注的支撑矩形边，未必贴合车辆轮廓或行人真实边缘。强灰度梯度可能来自
阴影、遮挡和邻车，不能直接当作标注边界。这是关键检验项，不能靠局部定理略过。

## 与已有工作的边界

以下为有针对性的原始来源审查，不等于已完成穷尽性新颖性检索。

| 工作 | 已有思想 | 不能作为本项目新贡献的部分 |
|---|---|---|
| [R3Det](https://arxiv.org/abs/1908.05612) | 用当前精炼框的位置做插值与特征对齐 | 框更新后重新采样特征 |
| [S2A-Net](https://arxiv.org/abs/2008.09397) | 按旋转 anchor 对齐卷积特征 | 旋转框引导空间读取 |
| [BorderDet](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123460528.pdf) | 显式提取边界特征辅助检测 | 边界包含有用定位信息 |
| [Oriented RepPoints](https://arxiv.org/abs/2105.11111) | 自适应点集捕获方向与几何信息 | 多点读取有利于旋转框定位 |
| [Bounding Box Regression With Uncertainty](https://openaccess.thecvf.com/content_CVPR_2019/html/He_Bounding_Box_Regression_With_Uncertainty_for_Accurate_Object_Detection_CVPR_2019_paper.html) | 联合学习框变换与定位方差 | 学习定位不确定性 |
| [Uncertainty-Guided Cross-Modal Learning](https://pure.kaist.ac.kr/en/publications/uncertainty-guided-cross-modal-learning-for-robust-multispectral-/) | 以 RoI/预测不确定性控制跨模态融合与引导 | 按模态可靠性做融合 |
| 本地 FressDet v2 | 光谱重采样与旋转等变特征处理 | 泛化的光谱与旋转组合 |

可检验的区别应是：**在一个预测 OBB 的不同边、不同沿边位置上，保留光谱观测对
平移、尺度和角度的不同作用，再由这些观测联合求解几何修正。** Fisher 信息、
广义最小二乘或 Bayes 本身都是已有工具，不算新的理论贡献。

## 可以支持设计的局部推导

以下是本次针对边界观测的推导，适用条件逐项给出。

### 1. 边界点如何观测五个几何自由度

设当前框为 \(b=(c_x,c_y,w,h,\theta)\)，局部轴为
\(u=(\cos\theta,\sin\theta)\)、\(v=(-\sin\theta,\cos\theta)\)。
边界点 \(p_j=c+\alpha_jwu+\beta_jhv\)，外法线为 \(n_j\)。
一次更新内固定 \(s=\sqrt{wh}\)，使用无量纲增量：

\[
z=(\delta c_x/s,\delta c_y/s,\delta\log w,\delta\log h,\delta\theta).
\]

法线位移的一阶近似为 \(d_j=a_j^\top z+O(\|z\|^2)\)，其中

\[
a_j^\top=
\left[s n_{jx},s n_{jy},
\alpha_jw(n_j^\top u),
\beta_jh(n_j^\top v),
n_j^\top J(p_j-c)\right],
\quad J=\begin{bmatrix}0&-1\\1&0\end{bmatrix}.
\]

这区分了某点看到的边界移动与整框参数修正，也明确各点对角度的作用。
它只在当前框附近、固定对应关系的一次局部更新中成立。

**为何不能过早平均：** 上边 \(p(t)=c+tu-hv/2\)、\(n=-v\) 的角度项为
\(-t\delta\theta\)。对称点位满足 \(\sum_jt_j=0\)，平均会抵消角度一阶项。
四边都先平均，在理想同质局部响应模型下，只剩平移和尺度的四个独立观测；
保留点位或带符号一阶矩 \(\sum_jt_jd_j\) 能保留角度信息。

这说明 v1 的观测压缩存在信息丢失反例，**不是证明整个 v1 无法估角**：
query、CNN 和 O² 原头仍有其他角度信息，真实非均匀纹理也会破坏上述对称条件。

### 2. 波段应按定位可靠性参与

更理想化的局部光度模型为

\[
y_{jk}=g_{jk}a_j^\top z+\epsilon_{jk},\qquad
\epsilon_{jk}\sim\mathcal N(0,\sigma_{jk}^2).
\]

\(g_{jk}\) 是法线方向的局部响应导数。若误差独立、方差已知，信息矩阵为

\[
\mathcal I=\sum_{j,k}\frac{g_{jk}^2}{\sigma_{jk}^2}a_ja_j^\top.
\]

因此关键不是某波段绝对亮度或类别激活高，而是其对位置移动的敏感度相对噪声有
多大，并且约束了哪个几何方向。小 \(g\) 几乎不提供位移信息；重复同一种几何方向，
即使信噪比很高，也不能消除其他方向的不可观测性。

原始响应的最优线性读出通常含带符号的 \(g\)，不能解释为正 softmax 注意力。
若网络输出共同单位的位移估计，独立无偏条件下才可按逆方差加权。
不同边的方差结构不同时，各边分别选择权重的最小总方差不高于约束为整框共享
权重的最小值；各边唯一最优权重不同且均有正权重时，优势严格。
这是可行域包含关系，不是对网络或 AP 的保证。

真实波段会相关，应使用 \(H^\top\Sigma^{-1}H\) 分析联合观测，不能把八个近乎
相同的波段算成八份独立证据。有系统错位时误差带偏，逆方差加权甚至会高置信地
偏向错误框。因此必须检查残差相关性、偏差和校准。

### 3. 从观测到受约束的几何修正

更可实现的版本是网络预测每个位置/波段的标注边法线位移 \(\hat d_{jk}\) 和误差结构，
而非把原始灰度差直接当位移。将 \(a_j^\top\) 沿波段堆成 \(A\)，用半正定可靠性
矩阵 \(W\) 求解：

\[
z^\star=\arg\min_z
\frac12(\hat d-Az)^\top W(\hat d-Az)+\frac{\lambda}{2}\|z\|^2
=(A^\top WA+\lambda I)^{-1}A^\top W\hat d,\quad\lambda>0.
\]

这个 5×5 系统的性质明确：

- 唯一解存在；无有效观测时 \(W=0\)，修正严格为零。
- 固定观测、固定 \(W\) 的当前局部二次目标上，最优值不大于零修正的目标值。
- \(\|z^\star\|\leq\|A^\top W\hat d\|/\lambda\)；仍需限制中心、尺度与角增量，
  避免超出局部线性范围。
- 样本重新编号同时置换 \(A,\hat d,W\)，不改变结果。
- 观测与坐标按旋转或等价框表示正确变换，且正则化/限制也相容时，求解结果遵守
  对应变换律。这是**求解器的条件性质**，不是普通 CNN 的端到端旋转等变。

无正则化、满列秩、线性无偏且协方差已知时，GLS 误差协方差为
\((A^\top WA)^{-1}\)。正则化会引入偏差；学习的 \(W\) 未经校准时不能称为真实
后验精度，也不能据局部目标下降声称非线性 IoU、loss 或 AP 必然提升。

## v2 最小实现及其与 O² 的关系

先在最终框上做一次细化，验证命题，再决定是否扩展到每层。不要同时修改 ADR、DN、
matcher 和全层精炼。

1. **保留点位的法线剖面。** 每边 K=4 个带位置点，沿法线读取有限多个偏移。
   query 与光谱特征共同选择支持当前对象的剖面；保留正负响应和点位关系。
   先比较 stride2 与现有 stride4，半径按短边归一化并设上限。
2. **几何观测及可靠性。** 预测各点/波段的法线位移、有效性与误差方差，有证据时
   加低秩相关项。GT 仅用于匹配后的观测 loss，不驱动推理采样。
   等价矩形在生成对应点前对齐；近方形歧义、错误匹配和遮挡需单独处理。
3. **显式修正。** 解上述系统，更新中心、正边长和周期角，输出严格矩形；
   可信观测少时回退到原框。保留 O² 内部 ADR 和辅助监督，将修正做成独立末端模块，
   为修正框增加监督。日志分别保存原框、修正框、观测和接受/回退原因，不让修正框
   冒充 ADR 原分布的直接解码结果。

当前 geometry_adapter 只支持特征残差，**不足以承载输出端求解器**。正式实现需
默认关闭的通用框修正接口，公共与私有改动分开提交。
O² 类别/LQE 分数与修正后定位质量可能失配：初版保留原分数，先报告固定 query
匹配下几何变化及常规 AP；质量重估应作为单独消融，避免把重排收益混同定位收益。

平方损失/高斯 NLL 只是起点。系统偏差、离群观测需要实证支持的稳健模型。
使用方差下界、proper scoring loss 和覆盖率/残差诊断，避免无限放大方差逃避监督；
不能要求每个波段都呈现同样强的可见边缘。

**本次未实现 v2。** v1 保留为隐式残差对照，其算子与 checkpoint 不在清理中改写。
先跑 O² 并保留预测，再判断该方向是否值得完整训练。

## 证据与实验顺序

### 真实 train 数据上的命题检查

使用场景分开的训练来源分析清单。若只有现有 1,000 图前缀，结论限于该子集。

- GT 附近施加已知小平移/角度/尺度扰动，检查剖面能否预测校正方向；再换成 O²
  真实预测，比较结论是否保持。GT 扰动只用于分析。
- 按类别、短边尺寸、拥挤度统计支撑边可见性，检查阴影/邻车干扰。
- 各边可靠波段差异需在相邻剖面宽度或独立子采样下可重复，排除少量样本的选择噪声；
  按图像/场景给置信区间，不能把同图目标当作独立场景。
- 检查预测方差与实际平方误差、残差偏差及跨波段相关性。
- 零/单边证据、近方形及较大初始偏差下，检查秩、条件数、回退和框稳定性。

若多数标注边不支持可靠局部校正，或预测偏差普遍超出剖面范围，就修改观测或放弃
核心主张，不能凭局部推导直接投入完整训练。

### 同一 20 轮配方中的因果消融

| 对照 | 排除的替代解释 |
|---|---|
| O² → v1 → v2 | 工程原型与新几何机制是否有效 |
| 同参数观测头 + 均匀/整框共享/点位可靠性 | 额外容量；局部可靠性是否必要 |
| 点位保留 vs 逐边平均；有无切向一阶信息 | 角度收益是否符合可观测性分析 |
| 同观测 + MLP 回归 vs 显式求解 | 几何求解结构是否必要 |
| 独立方差 vs 相关误差；正常 vs 打乱波段权重 | 校准与光谱信息是否实际参与 |
| 最终一次 vs 逐层修正 | 核心机制成立后验证迭代价值 |
| direct-angle 迁移 | 是否依赖 O² 的 ADR 实现 |

顺序：O² 收敛与资源测量 → 真实观测验证 → 最小 v2/隐式残差对照 → 关键消融。
不立即运行全部组合；所有正式训练使用同一 20 轮配方、数据和评估。

主表报告 ProbIoU AP50/AP75/mAP。机制分析还看固定 query 的中心/角度/几何 IoU
变化、几何 IoU AP、校准、秩/条件数、回退率与显存/吞吐。只提高 AP50、没有改善
对应框定位，不足以支持更精确几何细化的主张。

## 本次可执行证据

脚本：[theory_probe.py](../../../tools/research/bcsr/theory_probe.py)。

- Jacobian 与中心差分最大误差约 \(4.43\times10^{-9}\)。
- 每边 4 点的矩阵秩为 5；逐边平均后为 4；均值与切向一阶矩恢复为 5。
