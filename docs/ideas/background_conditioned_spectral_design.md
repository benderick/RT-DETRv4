## 一条主线

**多波段差异的判别价值取决于当前背景。我们要提取符合候选对象、又能够区别于周围背景的光谱证据，用它改善实例特征聚合。**

研究对象是多光谱信息如何服务目标识别。O² 保留为旋转检测基线；不改 ADR、旋转参数化和检测损失的研究主张。对齐仅保留为控制因素；不以“错位已经证明很少”为理由，也不把它加入主模块。

预期问题是：道路、植被、阴影等背景在多个波段上存在联合变化；变化大或与局部原型相似，不必然代表对目标有判别力。背景条件化的目的是改变证据的取舍依据，不是把背景全部压低，也不是把光谱异常直接当成目标。

## 证据为什么足以选它，但不足以宣布有效

固定抽取 384 张训练图、4,795 个对象，没有按实验成绩挑选；原像素探针中 4,712 个对象可测。逐波段方差与联合背景统计采用相同的真值辅助前景方向及检查像素，单位向量表示的平均 BA 为 81.19% 与 85.03%，相差 3.84 点。把规则冻结并移到原支持外的新背景像素，相差 3.99 点。这支持继续研究背景联合变化，而不是只凭几个图例提出模块。

收益并非覆盖所有对象：原探针提升超过 1 点的比例约 52.9%，退化约 21.1%；行人尤其需要审查。BA 是局部像素平衡准确率，不是 AP，且推理所需的目标方向在探针里由标注提供。因此当前结论是“主假设有数值依据，值得实施”，不能写成“已证明检测器普遍丢失这一信息”。

新增整数位置对照有 4,711 个可比较对象。对至少一个已验证背景位移超过 2 像素的 806 个对象，联合统计 BA 为原位置 82.01%、按估计读取 82.09%、反方向读取 82.09%；联合统计相对逐波段统计的优势为 4.88、4.92、4.41 点。位置干预未让该探针稳定变好，也未消除联合统计的平均优势。

这个结果不识别物理错位成因，也不否定对齐能改善检测。每个条件重新拟合的标注辅助判别器可能利用其他波段和不同局部差异；该探针不是有效的配准准确率或检测收益测量工具。到此停止将对齐作为主线的筛选实验。

## 冻结的机制：一次有背景参照的实例聚合

在 O² 的查询细化过程中增加一个光谱证据分支，主干继续提供对象语义和空间特征。分支从八波段输入产生小维度、保留波段来源的空间特征；针对每个候选对象，使用当前预测框和查询构造目标候选位置及周边背景支持。推理过程中不读取真值框、真值类别、真实分割或额外谱模板。

模块只有一个任务：为每个待聚合位置计算“对象兼容性 × 背景相对判别性”，然后形成查询的残差更新。

1. **保留光谱信息。** 使用轻量的逐波段空间提取，再映射到 8 维判别嵌入。首版使用约输入 1/4 分辨率的分支，避免先把小目标的光谱信息完全压入混合通道。它是学习表示，不命名为反射率或真实材料谱。
2. **形成背景参照。** 根据预测框周围较宽的二维区域取样，结合已有预测对象分数降低疑似对象的权重，计算加权均值和正则化协方差。支持图必须可导出；不能用长条环带拟合道路，却把未进入支持的树解释成已建模背景。协方差采用固定收缩和正数对角下限；支持不足时回退嵌入通道的对角统计。
3. **计算受对象兼容性约束的相对证据。** 查询预测目标原型及正的距离尺度；背景统计决定哪些跨通道变化更具有区分价值。兼容性约束防止“远离背景但也不像目标”的像素仅凭高对比分数获得大权重。
4. **更新实例特征。** 原查询语义权重与上述证据相乘，再汇总为小幅残差。保留原查询信息；不把一组全部很低的证据重新归一化成很强的确定性响应。

首版实现固定在第二层 decoder（索引 1），每实例 7×7 候选位置、11×11 背景网格，背景正方形边长为预测框长边三倍且至少 32 像素。分支先平均降采样到 1/4，再逐波段卷积及八维映射，以限制通道展开的内存占用。背景权重来自已有 encoder P3 对象分数，脱离梯度；小矩阵计算保持 FP32。参数量增加 76,288，双 3090 24GB 的实际峰值仍需目标机器预检。

### 计算定义

令 `z_p∈R⁸` 为候选位置经长度归一化的光谱嵌入，`μT(q)` 为查询给出并采用相同归一化的对象原型，`μB(q), Creg(q)` 为局部背景估计，`d=μT−μB`。背景相对方向和标准化投影为：

```text
w = solve(Creg, d)
s(q,p) = (z_p − μB)ᵀ w / sqrt(dᵀw + ε)
```

这一步本身是成熟的统计判别形式，不能包装成新发明。它区别于仅按各嵌入通道方差缩放，因为包含通道间的联合变化；嵌入通道已经学习混合原始波段，不能与原像素探针的逐波段统计混称。

查询另给出有正数下限的对角尺度 `A(q)`，计算对象兼容性和证据门：

```text
t(q,p) = exp(−||A(q)(z_p − μT(q))||² / (2D))
g(q,p) = t(q,p) · sigmoid(s(q,p) / τ)
Δq = W Σ_p softmax_p(semantic(q,z_p)) · g(q,p) · v_p
q_new = q + λ Δq
```

`D=8`，`τ` 固定，`λ` 初始为小值。这里的 `t、g` 是模型中的兼容性与聚合权重，不宣称是真实目标概率、校准置信度或物理可见度。参数化必须避免尺度趋零后兼容性失去约束；实现时检查尺度下限及门的分布。

目标原型来自查询而不是框内真值均值。训练仍以检测目标优化，是否能在 20 轮内学到有用的原型是本方案必须通过的检验。GT 辅助原型只允许用于单独注明的诊断上限，不能进入正式推理或作为主结果。

## 理论解释必须与模块对应

在目标均值差为 `d`、背景正定协方差为 `C` 的局部线性模型下，方向判别比

```text
J(w) = (wᵀd)² / (wᵀCw)
```

由柯西–施瓦茨不等式可得 `J(w)≤dᵀC⁻¹d`，取 `w∝C⁻¹d` 达到上界。这说明为何背景的相关变化会影响有效判别方向。它是标准结果；有限样本、非平稳背景、错误原型及学习特征都不自动满足准确估计条件。

上述投影的正侧可以无限延伸，所以单靠它不能解决“树比 bus 响应更高”的问题。对于未限定域的算子，正尺度保证距离增大时指数兼容性衰减。实际实现的嵌入位于单位球内，不据此声称任意远距离渐近拒绝；由于 `0<sigmoid(s)<1`，有 `0≤g≤t≤1`。这给出一个与结构直接对应的边界：仅增大背景相对投影不足以让任意远离原型的嵌入获得强证据。

该边界不保证树一定被拒绝：树的学习嵌入可能仍接近对象原型。后续可视化必须同时展示原型兼容性、背景相对分数和最终聚合贡献，检查错误到底发生在哪一项。AP 最优性和未知环境下的检测保证不在当前理论主张内。

新增查新已定位两项直接相关对照：2024 年的背景感知交叉注意力融合使用光照、对比度等背景条件引导模态／通道融合；2025 年 COFNet 使用框掩码对比损失和预测伪掩码指导融合。前者已读出版方方法段，后者目前核对出版方摘要，完整实现仍待精读。它们应进入实现前的相近方法核对，但不会因“涉及背景”就否决本方案。[出版方方法全文](https://www.mdpi.com/2072-4292/16/21/4034)，[COFNet 出版方记录](https://ieeexplore.ieee.org/document/11124580/)。

**当前冻结的是研究设计，不是已经证实的首创性声明。** 最终贡献应是：一种在未知目标原型和有限、混杂背景支持下仍可学习、可验证的光谱判别聚合机制，以及它在真实检测中的机制证据。若最后只剩“注意力里换成马氏距离”，贡献论证不成立，需要停止包装而不是新增无关模块补数量。

### 贡献组织与当前创新强度

建议组织为 **一个核心方法创新候选、两个支撑贡献**，不将三个算子硬拆成三个独立创新。主线保持不变。

1. **任务层面的机制贡献：背景依赖的光谱判别。** 在八波段实例检测中，验证局部背景的联合变化怎样影响有效目标证据，以及固定相似性聚合在哪些条件下未充分利用它。背景影响检测是已有认识，不能声称首次发现；贡献取决于群体证据、学习特征检查和针对性的干预。目前只有 GT 辅助像素证据，尚未证实检测器瓶颈。
2. **核心方法创新候选：实例条件的光谱判别算子。** 在无已知目标谱模板的条件下，由检测查询和当前背景共同形成判别方向，作用于多波段联合表示并参与实例聚合。贡献需要由可学习原型、背景支持和检测收益共同成立；仅将固定模板改成 MLP 输出或替换一个距离公式，尚不足以证明实质创新。
3. **结构与验证贡献：对象兼容性约束下的证据聚合。** 对“与背景不同、但也不符合对象”的表示限制其聚合贡献；从原图支持、源像素到实际更新逐项核查。当前指数兼容性乘 sigmoid 的实现是简洁候选，不单独宣称新理论。若它在相同背景判别下解决稳定出现的误取，且强于普通语义门，才有依据进一步凝练为第二个方法创新。

理论方面，Rayleigh 判别比与逆协方差方向是标准工具，`g≤t` 及远离原型时的衰减是结构性质。当前有理论解释，但还没有可单独声称的新理论成果。更有价值的分析应刻画有限、混杂背景支持及原型估计误差如何影响证据选择，并导出实际模块中的约束；不能为增加公式数量追加与机制无关的定理。

最近先例的核对依据：[MethaneMapper 会议正文](https://openaccess.thecvf.com/content/CVPR2023/papers/Kumar_MethaneMapper_Spectral_Absorption_Aware_Hyperspectral_Transformer_for_Methane_Detection_CVPR_2023_paper.pdf)，§3.4 的 SLF 式(2)和 §3.5 Query Refiner（出版方索引返回完整方法段，PDF 直连本轮为 403；尚未审查其代码）。该文采用物理甲烷吸收模板和地表类别统计，与本设计的未知实例原型有具体区别，但任务和输入差异本身不构成方法创新。

因此，主故事可以继续推进；实现与审查应优先证明第二项，第三项服务于同一机制。无须新增对齐或几何方向来凑创新点。

## 固定验证链与停止条件

主对照统一使用 O² 和 FressDet 论文优先的训练、输入及评价设置，正式主实验为完整训练集 9,156 张、20 轮。测试集用于最终评价，不用于选择图例、门限和模块结构。我们的检测成绩必须来自实际运行；本文件的像素 BA 不进入论文检测结果表。配置可比的既有论文结果可以用于整模型比较。

最小消融保持同一光谱分支、采样预算和查询接口：

| 对照 | 要回答的问题 |
|---|---|
| O²；O² 加普通查询光谱聚合 | 收益是否仅来自额外分支和计算量 |
| 同支持、嵌入通道对角背景统计 | 是否必须建模联合变化 |
| 同支持、联合统计，但去掉对象兼容性 | 是否重现“背景异常被当成目标证据”及其代价 |
| 完整模块 | 两项判据是否共同改善实际实例聚合 |
| 完整模块，将背景参照换成别图背景，其他量冻结 | 性能和证据变化是否确实依赖当前背景，而不是增加参数即可 |

最后一项首先作为冻结模型的机制干预，避免额外完整训练。换背景嵌入时须报告分布变化，只能支持“模块依赖什么”，不能单独作为自然场景因果结论。与 ReCoW／SFA 的同骨架模块对照在接口审查后选一个最接近的强对照实施；论文公布的完整检测结果提供另一层整模型比较。

机制图版固定包括：八波段／可读原图，实际进入统计的背景支持，实际采样位置，对象兼容性 `t`、背景相对分数 `s`、最终贡献 `a·g`。对同一个目标冻结嵌入和查询只更换背景参照，看方向与贡献怎样改变；每个嵌入点能回到原图位置。图例按类别、尺度和预定抽样规则展示，保留失败例。散点或谱曲线仅作辅助，不能取代源像素证据。

继续的条件：普通额外分支不能解释全部收益；联合统计优于对角统计对照；对象兼容性确实减少背景异常的误取；整体 AP 与多数类别的证据变化相容，而非仅少数例图获益。

停止或收缩的条件：非 GT 原型始终无法学好；门长期关闭或退化为常数；对角统计对照达到相同性能；更换背景参照几乎不改变结果；只有标注辅助像素 BA 提升而检测无收益。出现这些结果就否定对应的机制主张，不再追加配准、频域或几何模块挽救故事。
